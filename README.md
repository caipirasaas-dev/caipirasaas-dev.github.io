# CaipiraSaaS — Website & GitHub Pages

> **Software Artesanal · SaaS Sob Medida · Cloud Architecture**  
> Source code for [caipirasaas-dev.github.io](https://caipirasaas-dev.github.io/) / [caipirasaas.dev](https://caipirasaas.dev).

---

## 🚀 Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: GitHub Pages via GitHub Actions CI/CD

---

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```

---

## 📦 CI/CD & Deployment

Automated GitHub Actions workflow deployed on push to `main` branch via [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml).
